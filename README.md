# Compliance Route 101

A map-based, gamified Compliance 101 eLearning course (HTML, CSS and JavaScript).

## Files
- `index.html`: the course start page
- `css/styles.css`: design and layout
- `js/course-data.js`: all course text, questions and answers (edit content here)
- `js/app.js`: the map, modules and games
- `compliance-route-101-standalone.html`: the whole course in a single file, for tools that embed one file (Rise, Storyline web objects, LMS)

## Publish with GitHub Pages
1. Upload these files to the root of the `main` branch.
2. Go to **Settings → Pages**. Under **Build and deployment**, set **Source** to **Deploy from a branch**, choose **main** and **/ (root)**, then **Save**.
3. After a minute or two the course is live at `https://<your-account>.github.io/<repository-name>/`.

Learner progress is saved in each learner's browser.

> Production note: the scenario, terminology, policies, reporting channels and assessment answers should be reviewed and approved by PRCI before release.
